# Демо-бот записи клиентов

Готовый шаблон Telegram-бота для записи клиентов + FAQ. Подходит как демо для показа
локальному бизнесу (кафе, стоматология, репетиторский центр, автосервис и т.д.).

## Что умеет бот
- Главное меню с кнопками
- Пошаговая запись: услуга → дата/время → телефон
- Раздел FAQ с частыми вопросами
- Просмотр своей последней записи
- Уведомление владельцу бизнеса о каждой новой записи

## Запуск за 5 минут

1. **Создать бота в Telegram:**
   - Напиши в Telegram боту `@BotFather`
   - Команда `/newbot`, придумай имя и username
   - Получишь токен вида `123456:ABC-DEF1234ghIkl...`

2. **Узнать свой chat_id (для уведомлений):**
   - Напиши боту `@userinfobot`, он пришлёт твой ID

3. **Установить библиотеку:**
   ```
   pip install python-telegram-bot --break-system-packages
   ```

4. **Вставить токен и chat_id** — либо прямо в `bot.py` (переменные `BOT_TOKEN` и
   `OWNER_CHAT_ID` в начале файла), либо через переменные окружения:
   ```
   export BOT_TOKEN="твой_токен"
   export OWNER_CHAT_ID="твой_chat_id"
   ```

5. **Запустить:**
   ```
   python bot.py
   ```

6. Открой своего бота в Telegram и нажми `/start`.

## Как адаптировать под конкретного клиента

Всё, что нужно поменять под нового заказчика, находится в верхней части `bot.py`:
- `BUSINESS_NAME` — название бизнеса
- `SERVICES` — список услуг
- `FAQ` — вопросы и ответы

Для реального использования (не демо) стоит:
- Подключить базу данных (SQLite/PostgreSQL) вместо хранения в памяти
- Добавить проверку занятых слотов времени
- Добавить админ-панель для владельца (список всех записей, отмена/подтверждение)
- Разместить на сервере (VPS) или сервисе типа Railway/Render, чтобы бот работал 24/7
